# MakeCuts - Инструмент для нарезки видео по таймкодам

Простой скрипт на Python для нарезки видеофайлов на части по указанным временным меткам. Доступны две версии: консольная и с графическим интерфейсом.

## Требования
- Python 3.6+
- Для GUI версии: Tkinter (обычно входит в стандартную поставку Python)
- Установленные зависимости:
```bash
pip install moviepy
```

## Установка
1. Скопируйте файл `MakeCuts.py` в вашу рабочую директорию
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Консольная версия (MakeCuts.py)
### Базовый пример
```python
from MakeCuts import cut_video_by_timestamps

cut_video_by_timestamps(
    video_path="input.mp4",
    timestamps="00:00:10,00:00:30,00:01:00"
)
```

### Параметры функции
- `video_path` (обязательный): Путь к исходному видеофайлу
- `timestamps` (обязательный): Строка с таймкодами в формате "ЧЧ:ММ:СС", разделенными запятыми
- `output_dir` (опциональный): Папка для сохранения клипов (по умолчанию "clips")

### Примеры таймкодов
- Простая нарезка: `"00:00:10,00:00:30"`
- Множественные отрезки: `"00:00:05,00:00:15,00:00:30,00:01:00"`

## Версия с графическим интерфейсом (MakeCutsGUI.py)

### Запуск
```bash
python MakeCutsGUI.py
```

### Описание интерфейса
1. Поле "Видеофайл" - для выбора исходного видео
2. Текстовое поле - для ввода таймкодов в формате ЧЧ:ММ:СС через запятую
3. Кнопка "Нарезать видео" - запускает процесс обработки
4. Прогресс-бар - отображает ход выполнения

### Особенности
- Автоматически создает папку для выходных файлов
- Сохраняет клипы в формате MP4 с кодеком H.264
- Имена файлов генерируются автоматически (clip_1.mp4, clip_2.mp4 и т.д.)

## Запуск напрямую
Можно редактировать параметры в секции `if __name__ == "__main__":` и запускать:
```bash
python MakeCuts.py
```

## Ограничения
- Требуется минимум два таймкода для нарезки
- Поддерживаются только видеофайлы, совместимые с библиотекой moviepy
